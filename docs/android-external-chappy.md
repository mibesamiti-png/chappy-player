# Android ファイルから直接 .chappy を開く

次期APKでAndroidのファイル画面から `.chappy` をタップし、Chappy Playerに渡す機能を追加する。

## 手順
1. Androidの「ファイル」「ダウンロード」画面で `.chappy` をタップする。
2. 「Chappy Playerで開く」を選択する。候補に表示されるかはファイル管理アプリのMIME判定に依存する。
3. Chappy Playerに表示されたアプリ名・ID・バージョンを確認して追加・更新を承認する。
4. 追加・更新後にホームでミニアプリを起動する。

## 安全性
- Androidの `content://` 経由で共有されたファイルのみを処理。広域ストレージ権限は不要。
- 表示名が `.chappy` で終わることを確認し、12MiBを上限として専用キャッシュへコピー。
- 既存のZIP preflight、ID検証、確認ダイアログを通すまでは実行も保存も行わない。
- 一部のファイル管理アプリは未知拡張子を別MIMEとして扱うため、Chappy Playerが候補に出ない場合がある。そのときはアプリ内の「.chappyを追加 / 更新」を利用する。
- 汎用ZIPファイルを開く候補にも表示される可能性があるが、`.chappy`以外は拒否する。

## 実機テスト
ファイル画面と共有画面の両方で起動・確認・追加を試す。間違った拡張子／12MiB超の拒否、同一IDの更新、保存データの維持、連続受信も確認する。
Androidでの実機動作は次期正式APKで検証する。
