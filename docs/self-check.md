# Chappy Player: 端末セルフチェック

開発者向けの簡易環境診断。ホームのチェックアイコンから開き、**セルフチェックを実行**を押して開始する。

## 実行する4項目

- **保存データ**: 検証専用の一時フォルダでJSON保存・読み込み・削除を試す。実際のミニアプリの保存データは変更しない。
- **インストール状態**: 全インストール済みアプリの`manifest.json`と`index.html`の存在、アプリIDとバージョンの整合性を確かめる。
- **ローカル配信**: 検証専用の一時HTMLを127.0.0.1で配信して、HTTP 200・ブートストラップスクリプト挿入・CSPを確認する。
- **診断ログ**: 一意の検証マーカーをログへ書き込み、実際のJSONLファイルに保存されたかを確認する。

結果は**PASS/FAILと処理時間**で表示し、コピーして相談に添付できる。
外部ネットワークへ情報を送信する処理はない。

## 限界

このセルフチェックはWebView実描画、Androidのカメラ・マイク、ファイル選択画面、
実際のAPKのインストールや署名、UI描画速度を検証するものではない。
**このテストのPASSはAndroid実機での完全な動作保証ではない。**

### 動作確認の順序

1. セルフチェックで全4項目の結果を確認する。
2. 「サンプルメモ帳を追加してテスト」でアプリを取り込み、WebView描画を確認する。
3. メモを書いて再起動後に残るか確認する。
4. メモ帳の「テスト用エラー」後に診断ログを確認する。
5. `.chappybackup`でエクスポート・復元を確認する。
6. エラーが出た場合、セルフチェックのコピー結果と診断レポートを送る。

テストはユーザー端末で行い、結果の外部送信は明示的にコピーして共有した場合に限る。
