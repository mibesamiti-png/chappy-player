# QA-03: Androidでサンプルメモ帳が起動しない場合

実機からの報告（2026-11-04）：

- QA-01: Chappy Playerのホーム起動 成功
- QA-02: 内蔵メモ帳の追加 成功
- QA-03: メモ帳を開いて文字入力 エラー
- QA-04: メモ保存 未確認
- QA-13: 端末セルフチェック 未確認
- 確認端末: Xiaomi 11T Pro / Android 14 / HyperOS 1.0.20.0.UKDJPXM

**現時点で根本原因は未確定。**

## 起動診断の改良

- ミニアプリのHTMLを開く前にlocalhostサーバーをHTTP GETで検査
- WebViewの読み込み進捗を表示
- 20秒で読み込み未完了ならタイムアウトを表示
- ページ全体の読み込み失敗と、画像等の個別リソース失敗を区別
- JavaScript Bridgeの初期化完了をWebView上で確認
- 読み込み失敗の詳細、リトライ、診断ログへ進むボタンを表示
- WebViewの表示領域を`Positioned.fill`で確保

## 次の実機チェック

1. 修正版ARM64 APKをインストール。新しいデバッグ署名と競合する場合があるため、アンインストールする前に必要な保存データのバックアップを取得。
2. メモ帳をタップ。読み込み率／WebViewエラー／JavaScriptブリッジが使えるか確認。
3. 失敗画面にある「このアプリの診断ログを開く」からログをコピー。
4. ホームへ戻って端末セルフチェックを実行。4項目の成功／失敗を確認。
5. 診断ログとセルフチェックの結果を、個人情報がないか確認したうえで共有。

**注意:** HTMLローカル配信の単体テストが成功しても、Android WebView自体の動作は保証されない。
