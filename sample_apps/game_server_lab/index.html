Chappy Game Server Lab

自分のゲームサーバーに接続するための、安全な通信テスト用ミニアプリ。

リアルタイム接続（WSS）

未接続

接続先を許可した後、サーバーと通信します。30秒以上応答がない場合は失敗として表示します。
接続はユーザーが指定したサーバーへのみ。受信データは表示だけで、カメラ・ファイル・振動などを勝手に実行しません。

HTTPS APIテスト

GETは本文を送りません。POSTはこの欄のJSONを送信します。公開テスト先へ個人情報や秘密情報を送らないでください。 リダイレクトは禁止。リクエストは8KiB、レスポンスは64KiB以下。平文HTTP/WSやローカルIPへの接続はこの段階では不可。
