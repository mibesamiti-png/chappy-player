PC Transfer Lab

Windows ↔ Android の本人が選んだ1ファイルを安全に転送する機能のテスト補助画面。

このミニアプリ自体は転送・PC接続を行いません。 ファイルは Chappy Player本体の「Network Lab → PC連携」で送受信します。 この画面にファイル内容・鍵・通信ログは渡されません。

PC / Android 操作手順

  1. Windows Companionの端末署名鍵を準備する。
  2. PCで Start-ChappyFileOnceV3.cmd を明示起動し、転送するファイルを1つ選択する（最大4MiB）。
  3. Androidの Network Lab → PC連携からQR-v3を読み、両端末のコードを照合する。
  4. PCで通常の YES、Androidで端末署名を許可する。
  5. Androidの「PCで選択した1ファイルを受信」を押し、PCで追加の SEND を入力する。
  6. Androidでファイル名と容量を確認して受信を許可。100％の転送とSHA-256照合後、Androidの標準保存画面で保存先を選ぶ。

1回限り・転送量上限4MiB・16KiBチャンク・途中再開は未対応。期限切れ・中断後は新しいQRが必要。

Android → Windows（R5B）手動確認

  1. PCで Start-ChappyUploadOnceV3.cmd を起動し、まだ存在しないローカル保存先をフルパスで指定。
  2. スマホのNetwork Lab → PC連携で新しいQR-v3（upload=1）を読み、本人確認。PCでは YES。
  3. Androidの「Windowsへ1ファイルを送信」を押し、選択ファイル名がPC保存先と同じことを確認（最大4MiB）。
  4. PCで別の RECEIVE を入力し、Androidでも独立して送信を承認。
  5. 転送100％、SHA-256検証後にWindowsの新規ファイルが作成されたか確認。
  6. 途中キャンセル、期限切れ、既存ファイル上書き、二度目の転送の拒否も確認。

このLabは手順案内と手動QA記録のみ。mini-app JSへのファイル転送・PCアクセスAPIはありません。実機未確認をPASSと誤記しないでください。
