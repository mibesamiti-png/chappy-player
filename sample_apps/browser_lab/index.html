Browser Lab

このミニアプリにブラウザ実行・LAN診断・ネットワーク権限はありません。 PCの操作、WebView/Cookie管理、通信診断はChappy Player本体の画面から本人が明示的に実行してください。チェックは自己記録です。

本体ブラウザの確認手順

  1. 最新Debug版でホームの地球アイコンかNetwork Labから「ブラウザ」を開く。
  2. 最初にJavaScriptがOFF、カメラ/マイクのサイト要求が拒否されることを確認する。
  3. 公開HTTPSのアドレスだけ移動できることを確認。HTTP、localhost、LAN内IP、file、intent、data、javascript等は拒否されること。
  4. 戻る/進む/更新を確認。信頼できるサイトだけJSを手動ONにし、アプリ背景化でOFFに戻ること。
  5. CookieとキャッシュはAndroidの他のWebViewにも共有される可能性がある。削除時の警告を確認してから実行する。

本体ネットワーク診断の確認手順

  1. Network Lab→「ネットワーク接続診断」を開く。画面表示時点で外部通信が始まらないこと。
  2. 「診断を開始」押下後の別承認画面で、example.comへのDNS/HTTPS HEADの説明を確認する。
  3. 同意後だけネットワーク接続数・DNS結果・HTTP応答を確認。端末IP、URLの履歴、機器リストは記録しない。
  4. 拒否、オフライン、Wi-Fi切断、背景化で通信を中断・結果を破棄し、勝手に再実行しないこと。
  5. 既存Game Server Labの通信権限・接続同意は変更しない。本LabからWSS/API操作や端末診断を呼び出さない。
