Chappy File Lab

ミニアプリの設定・メモ・JSONをスマホのファイルと安全にやり取りする実験室。

ファイルを開く

Androidの標準ファイル選択画面が開きます。選んだファイルの内容だけ読み取り、64KiBを超えるものは拒否します。

編集・保存

ファイルの読み書きはユーザーの操作時だけ。別のアプリやPCに勝手に送信しません。バイナリ・大容量ファイルは下の専用保管庫から扱えます。

大容量ファイル保管庫

ZIP・音声・画像・3Dファイルなどを、ミニアプリだけの非公開保管庫に取り込めます。

転送待機中

「ファイル一覧を更新」で表示します。
1ファイル最大256MiB、合計512MiB・32ファイルまで。転送中は処理量を表示し、キャンセルもできます。取り込み元は変更せず、書き出し先は毎回Androidで選択します。ミニアプリの削除やデータ消去で保管庫も消えるので、必要なファイルは書き出してください。
